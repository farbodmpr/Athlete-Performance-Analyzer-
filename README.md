
# Athlete Performance Analyzer

## Overview
A Python-based application that analyzes athlete performance using individual performance records and calculates average scores.

## Features
- Register up to five athletes.
- Store athlete information including name, sport, and weight.
- Record three performance scores for each athlete.
- Calculate individual performance averages.
- Classify athletes based on performance levels.
- Calculate the overall performance average.
- Identify the best and weakest athletes.
- Sort athlete names alphabetically.
- Search for registered athletes.
- Validate user inputs.

## Technologies Used
- Python 3
- Variables and Data Types
- Lists and Nested Lists
- For Loops
- Conditional Statements
- String Methods
- Mathematical Operations
- Sorting and Searching

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```
